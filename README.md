# 🎉 MacParty

**MacParty** is a collection of web-based macOS emulators and simulators built entirely with vanilla HTML, CSS, and JavaScript. Experience the nostalgia of classic Mac OS environments and system behaviors right in your modern web browser.

🌐 **Live Demo**: [https://nik-dev001.github.io/macparty/](https://nik-dev001.github.io/macparty/)

---

## ✨ Features

- 💻 **Mac OS X Leopard Emulator**: A fully functional, browser-based recreation of the legendary 2007 operating system. Features include:
  - Interactive Dock
  - Draggable windows
  - Spotlight search simulation
  - Classic Aqua interface styling
- 💀 **Kernel Panic Simulator**: A realistic macOS kernel panic simulation with gradual, authentic-looking system log output.
- 📱 **Responsive Design**: Optimized to work across different screen sizes and devices.
- ⚡ **Zero Dependencies**: Built with pure, vanilla web technologies. No frameworks, no build steps.

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3** (Custom properties, Flexbox, Grid)
- **Vanilla JavaScript** (ES6+)
