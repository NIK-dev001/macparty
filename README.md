```markdown
# 🎉 MacParty

MacParty is a collection of web-based macOS emulators and simulators built entirely with vanilla HTML, CSS, and JavaScript. Experience the nostalgia of classic Mac OS environments and system behaviors right in your modern web browser.

## ✨ Features

- 💻 **Mac OS X Leopard Emulator**: A fully functional, browser-based recreation of the legendary 2007 operating system. Features include:
  - Interactive Dock
  - Draggable windows
  - Spotlight search simulation
  - Classic Aqua interface styling

- 💀 **Kernel Panic Simulator**: A realistic macOS kernel panic simulation with gradual, authentic-looking system log output.

- 📱 **Responsive Design**: Optimized to work across different screen sizes and devices.

- ⚡ **Zero Dependencies**: Built with pure, vanilla web technologies. No frameworks, no build steps.

## 🛠️ Tech Stack

- HTML5
- CSS3 (Custom properties, Flexbox, Grid)
- Vanilla JavaScript (ES6+)

## 📂 Project Structure

```

├── macos.html          # Mac OS X Leopard emulator entry point
├── about-macos.html    # Information page about the Mac OS X emulator
├── kernel-panic.html   # Kernel panic simulator entry point
├── about-kernel.html   # Information page about the Kernel Panic simulator
└── README.md           # You are here!

```
# 🎉 MacParty

MacParty — это коллекция веб-эмуляторов и симуляторов macOS, полностью написанных на чистом HTML, CSS и JavaScript. Окунись в ностальгию по классическим средам Mac OS и системному поведению прямо в современном браузере.

## ✨ Возможности

- 💻 **Эмулятор Mac OS X Leopard**: полностью функциональная браузерная реконструкция легендарной ОС 2007 года. Включает:
  - Интерактивный Dock
  - Перетаскиваемые окна
  - Симуляцию поиска Spotlight
  - Классический интерфейс Aqua

- 💀 **Симулятор Kernel Panic**: реалистичная имитация паники ядра macOS с постепенным, аутентичным выводом системного лога.

- 📱 **Адаптивный дизайн**: оптимизирован под разные размеры экранов и устройства.

- ⚡ **Без зависимостей**: построен на чистом веб-стеке. Никаких фреймворков и шагов сборки.

## 🛠️ Технологии

- HTML5
- CSS3 (кастомные свойства, Flexbox, Grid)
- Чистый JavaScript (ES6+)
```
