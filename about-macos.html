Mac OS X Leopard

О проекте

Эмулятор Mac OS X 10.5 Leopard. Полноценная виртуализация операционной системы Apple, выпущенной в 2007 году. Проект воссоздает оригинальную пользовательскую среду, включая фирменный интерфейс Aqua, работу с файловой системой и классические системные утилиты, адаптированные для запуска непосредственно в веб-браузере.

✨ Возможности

  • Рабочий стол с обоями
  • Dock с анимацией
  • Перетаскиваемые окна
  • Spotlight поиск
  • Меню Apple
  • Системные иконки
  • Анимации открытия/закрытия
  • Работает в любом браузере

🚀 Как использовать

Онлайн: Просто открой macos.html в браузере

Локально: Скачай файл и открой двойным кликом

На GitHub Pages: Залей в репозиторий и включи Pages
